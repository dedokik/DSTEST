# ИИ-помощник по складскому учёту (MVP, тестовое задание)

Детерминированный расчёт + честный AI-слой: все числа — только из данных, без выдуманных остатков/цен.

## Структура

- `dataset.json` — данные Приложения 1 (M1–M8, расход/остатки, 15 вопросов).
- `catalog.json` — справочник Приложения 2.
- `src/config.py` — все пороги и коэффициенты (без магических чисел).
- `src/normalizer.py` — Часть 1: `normalize_movement(text) -> dict`.
- `src/forecast.py` — Часть 2: `forecast_demand(history, sku, horizon_days, params) -> dict` (без LLM).
- `src/assistant.py` — Часть 3: `answer_question(question, context) -> tuple[dict, float, str]` (правила + опциональный LLM, fallback по умолчанию).
- `src/data_loader.py` — загрузка JSON.
- `main.py` — прогон всего пайплайна одной командой.
- `tests/` — pytest: даты, единицы, округление до упаковки, интент/unknown.
- `RESULTS.md` — таблицы и обоснования.

## Установка и запуск

```bash
pip install -r requirements.txt
pytest -q
python main.py --out results.json --print
```

LLM-путь Части 3 включается только при `OPENAI_API_KEY` (иначе работает детерминированный fallback на правилах, без ключей и интернета).

## Архитектура решения

1. **Нормализация** — regex-парсинг дат (ISO, `ДД.ММ.ГГГГ`, `ДД/ММ/ГГ`, `1 марта 2026`), операций (приход/расход/списание/возврат/корректировка), SKU (`OIL-001`/`oil 001`/`WRAP 030` + маппинг по названию для M8), локаций (`MS-01`, `Сочи`, `Красная Поляна`), количеств (`2 канистры по 5 л`, `450 мл`, `4 уп. по 50 пар`, отрицательная корректировка) с переводом в базовую единицу из `catalog.json`, партий (`B-...`) и документов (`НК-345`).
2. **Прогноз** — среднее последних 4 недель (ловит тренд и сдвиг уровня), пропуски → медиана, сдвиг уровня (>2x) → новый уровень, округление вверх до упаковки/мин. партии, confidence от волатильности/длина истории/пропусков.
3. **Ассистент** — скоринг интентов по ключевым фразам + разрыв top1–top2 + проверка обязательных параметров; числа в ответе только из Части 2; по срокам годности/ценам честно отвечает «нет данных», а не выдумывает.

## Мотивация участия в проекте

**Почему интересен проект.** Проект привлекает сложной и необычной архитектурой: связка детерминированных расчётов, нормализации неструктурированных данных и честного AI-слоя без галлюцинаций. Такие задачи на стыке Data Science и продуктовой разработки завлекают сильнее типовых CRUD-проектов.

**Роль в команде.** Вижу себя разработчиком, который много и плотно работает с кодом: реализация расчётных модулей, парсинга, прогнозов, покрытие тестами и доведение MVP до рабочего состояния.

**Время.** Готов уделять 40+ часов в неделю вплоть до полного завершения проекта.
